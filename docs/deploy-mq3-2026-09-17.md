## 4. `botflow restart` 真实 Linux 集成验收（fix-restart）

在隔离 workspace `/tmp/bfws2`、端口 4112 上实跑（不干扰 supervisor 实例）：

| 步骤 | 实测 |
|---|---|
| `python -m botflow version` | `botflow v3.0.0` —— **F1 生效**（修复前 runpy 直接报 `No module named botflow.__main__`） |
| 在**全新 workspace** 上 `restart` | `{"ok": true, "pid": …}`，PID 文件已写 —— **F9 生效**（修复前会早退 `No PID file found`） |
| 服务是否真的起来 | **是**：`/health` 在 **t≈14s** 转 `200`，`botflow status` 报 `Running: yes / Health ok`，err log 有完整 uvicorn 启动日志 |
| `botflow stop` | `{"ok": true, "Service (PID …) stopped."}`，端口随即释放 |
| POSIX 分支 | `start_new_session=True` 在真实 Linux 上生效（父进程返回后子进程继续存活） |

> ⚠️ **重要边界发现**：该机 `import botflow` + uvicorn 就绪**约需 13–14s** 冷启动，而
> `restart_service` 的 `startup_grace` 默认只有 **2.0s**。因此「子进程 2s 之后才死」的情形
> 仍会被判成功（`docs/tasks/fix-restart_features.md` §8.3 已声明的残留风险，在慢机上窗口更大）。
> 生产路径是 supervisor 的 `startsecs=5` + `autorestart=true`，不受此影响；
> `botflow restart` 属运维手工命令，建议在慢机上显式 `--startup-grace`（当前 CLI 未暴露该参数）。

## 5. 本次顺带发现的两个问题（**均非本次部署引入**）

### 5.1 全量单测在 main 上有 8 个既有失败（已用基线证实）

在同一台机、同一套命令下：

| 版本 | 结果 |
|---|---|
| `c993667`（本次部署） | **716 passed / 8 failed** / 11 deselected，239s |
| `08973e9`（本次改动之前） | **695 passed / 8 failed** / 11 deselected，126s |

**失败集合完全一致**，全部是 router / cooldown 相关：

- `tests/test_pipeline_strategies.py::TestRoundRobinStrategy::test_counter_overflow_protection`
- `tests/test_router.py::TestPipelineEngineRouting::{test_no_models_in_group, test_no_available_provider, test_disabled_provider_skipped, test_route_stream_all_on_cooldown_fallback}`
- `tests/test_router_full.py::{test_route_no_models, test_route_non_stream_all_cooldown_raises, test_route_stream_all_cooldown_no_fallback_raises}`

典型断言不符：期望 A 却抛 `NoAvailableModelError: Group 1 has no available models for streaming`，
且日志有 `Model 1 entered cooldown for 1000s`。

> ⚠️ **更正（2026-09-17 晚）**：当时给出的「疑似**跨用例全局冷却状态污染**」**是错的**。
> 事后在 mq3 上把 8 条用例**单独跑**（不加载任何其它用例），**同样 8 条全挂**；
> 「单独跑 / 按文件跑 / 三文件合并跑」三种跑法的失败集合**逐字一致** → 不存在任何跨用例污染。
> 真实根因是：① `RoundRobinStrategy` 实现漏了设计规定的计数器 wrap；
> ② LangGraph 节点把异常压成字符串导致**异常类型丢失**；③ 1 个与 `design.md §3.5` 冲突的**过时用例**。
> 详见 **`docs/router-test-failures-2026-09-17.md`**；三项均已修复并随 **`3.1.0`** 发布。
